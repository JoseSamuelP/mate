# Mate

App de práctica de matemática (nivelación PRE-ESAN). Modo oscuro, sin internet, instalable.

Ábrela en el celular con Chrome: https://josesamuelp.github.io/mate/ → menú ⋮ → **Instalar app**.

El código fuente y su historial están en el repositorio `app-matematica`; este repositorio solo publica la app.
